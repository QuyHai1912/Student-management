**🎓 Student Management System**

A full-stack web application for managing students, built with React (Frontend) and ASP.NET (Backend) using RESTful API.

**🛠️ Technologies Used**

**Frontend**

- React (Vite)
- HTML, CSS, JavaScript
- Fetch API

**Backend**
- ASP.NET (C#)
- RESTful API
- SQL Server (or your database)

**🚀 Getting Started**

**1. Clone repository**

git clone https://github.com/QuyHai1912/Student-management.git

cd Student-management

**2. Run Backend (ASP.NET)**

- Open folder BE with Visual Studio
- Run project (F5 or Ctrl + F5)
- Backend will run at: https://localhost:xxxx

**3. Run Frontend (React)**

- cd FE
- npm install
- npm run dev
- Frontend will run at: http://localhost:5173
